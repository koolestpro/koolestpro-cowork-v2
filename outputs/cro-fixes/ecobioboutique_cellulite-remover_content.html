How to use
In Figma, use annotation numbers 1–8 pointing to the same elements across all 3 graphics. Before/After — numbered dots on the After screenshot. Psychology Map — curved arrows from each question to the corresponding element. Decision Guide — curved arrows from each "what it achieves" label to the corresponding element. Column 2 of the table = dot placement target. Column 3 = Psychology label. Column 4 = Decision Guide label.
