# X (Twitter) caption playbook (2026-09-13)

Derived from Ridwan's own best-performing posts on X (verified account). The winners are not
long explanations. They state one insight, then let the before/after image prove it.

Examples this is built from:

| Post | Impressions | Page tool |
|---|---|---|
| GetFit NG, "Same product. Different outcome." | 512 | Lovable, AI-regenerated product image |
| Petticoat Fair, "answering one thing: Customer questions" | 515 | Figma Make |
| Champion Biotics, "Client sent a rough PNG." | 229 | Figma |
| Petticoat Fair, "around one thing: Clear answers" | 65 | Figma Make |

---

## The anatomy (every winner uses it)

1. **One-line hook.** A short declarative that ends in a period. Often a "same input, different
   result" frame. No clickbait, no question mark.
2. **A single lens.** Name the one thing the page was redesigned around, in three or four words.
3. **A scannable list in the middle.** Cross/check pairs, arrows, or numbers. Never a paragraph.
4. **A closing reframe.** A formula-like line that generalizes the fix so it reads as a lesson,
   not a portfolio entry.
5. **No hashtags. Usually no link.** The graphic does the showing. The text does the teaching.

Sentences are short. Line breaks do the pacing. First person, plain words, no marketing jargon.

## The four proven patterns (with Ridwan's own examples)

### 1. The contrast frame (best performer)
```
Same product. Different outcome.

The first page:
X No clear value
X Weak CTA
X No urgency

The second:
OK Clear result
OK Strong structure
OK Better conversion triggers

Most stores don't need more traffic...
They need clarity.
```

### 2. The single question (numbered)
```
Redesigned this PDP by answering one thing:

Customer questions.

1 Can I see it clearly?
2 Should I buy now?
3 Can I trust this?
4 What is it?
5 Why buy?
6 What makes it good?
7 Which one do I pick?

Same product.

Better answers = better conversion.
```

### 3. The single lens (outcomes)
```
Redesigned this PDP around one thing:

Clear answers.

-> See the product instantly
-> Know why to buy now
-> Trust it at a glance
-> Understand it fast
-> Feel the value
-> Spot the benefits
-> Choose without thinking

Same product.
Better answers = better conversion.
```

### 4. The origin story
```
Client sent a rough PNG.

That was it.

No system. No structure. Just an idea.

I turned it into:

-> a fully designed product page (Figma)
-> clean Shopify code (AI-assisted)
-> reusable sections across the site

Now they can edit anything, anytime.
```

## Per-stream starters

### CRO Fix
- **Hook:** the page's single biggest miss, in one line ("No price. No rating. No product on screen one.").
- **Lens:** the one question the rebuild answers ("What does it actually cost?").
- **List:** 3 to 7 findings, or before/after pairs.
- **Close:** the reframe ("Same product. Better answers = better conversion.").
- **Always state the page type** in the opening line (PDP, homepage, landing page). Hard rule 6.

### Template / page showcase
- **Hook:** the objection the page removes, or plainly what the page is.
- **Body:** what the page does, section by section, in plain language. One idea per line.
- **Concept brand:** always label it ("a demo brand I made up, not a client"). Never imply a
  concept brand was a client. Highest-stakes rule in the project.
- **CTA:** soft is fine ("DM me", "Reply and tell me what you sell") or a real service URL.

---

## Hard rules (project-wide, non-negotiable)

- No em dashes anywhere.
- Run the full humanizer pass before final.
- No hashtags on X.
- Real line breaks, never markdown literals.
- Never fabricate a result, number, or quote. Every number must be traceable to the live page.
- Never imply a concept brand was a client.

---

## Length: hard 280, always counted

Every X caption must be **under 280 characters**, newlines included. Ridwan confirmed (2026-09-13)
that he upgraded to Premium recently, but every one of his winning posts is still under 280. The
GetFit winner, the best performer at 512 impressions, is about 230 characters. The advantage is
the anatomy above, not long-form posting.

Count the real string before it ships. A caption at or over 280 is not postable. No exceptions.
The patterns above are written to fit; when a draft runs long, cut a list item, not the close.
