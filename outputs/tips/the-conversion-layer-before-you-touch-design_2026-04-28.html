3C FRAMEWORK
Clarify → Construct → Convert
1
CLARIFY
What does this page need to communicate? What's the one question the buyer needs answered?
2
CONSTRUCT
What's the logical flow of the buyer's journey on this page? Does the layout follow that flow?
3
CONVERT
What's the single action this page must drive? Is every element pointing toward that one action?
