# Client Report Templates

Templates for all five client deliverables. Every document uses the pdf skill for generation. Every document carries @koolestpro branding and ends with the CTA.

---

## BRANDING BLOCK (apply to all documents)

```
Header: Ridwan Adekunle · @koolestpro · Shopify CRO & UX
Footer CTA: Ready to implement these changes? Let's talk →
            [booking link / DM @koolestpro on Instagram or LinkedIn]
```

Use a clean, minimal layout. Black or dark header bar, white body, orange accent (#FF9500) for section labels and priority badges.
