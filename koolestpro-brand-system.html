⚡ Flexible Layout Philosophy
Slides are not locked to a single template. Each slide's layout is determined by its content type. The brand stays consistent through typography, spacing, and the gradient system — not through rigid structure. A "tips" post may have 4 completely different slide layouts and that is intentional.

Cover slides → Big watermark number, headline, gradient rule, swipe indicator
Problem slides → Large decorative symbol, multi-weight headline, divider, body text
Concept slides → Color-coded accent, funnel path chips, explanation card
Rule/Quote slides → Large quote mark, bold claim, accent key phrase
CTA slides → Centered avatar, one question, gradient button

Content slides may use contextual accent colors (e.g., blue for cold audience, green for warm) while cover/CTA slides always use the brand gradient.

06 — Voice & Tone

How We Write

Write in plain Nigerian English: direct, practical, confident, and clear. Use lived context when it is relevant. Do not force slang or Pidgin.

✓ Do
"This product page gives shoppers too many reasons to leave. Start here."
"State the change, then the verified result: we moved the CTA above the fold and conversion rate changed from [x] to [y]."
"Diagnose before you redesign."
"Lead with a specific metric only when you can name its source."
✕ Don't
Vague promise with no proof.
Generic introduction that delays the point.
Buzzword stack with no concrete action.
Throat-clearing instead of a clear point.
