SNIPPET 01 / 05
Dynamic Urgency Timer
Cart page — live countdown that resets per session. Creates time pressure without fake evergreen timers.
LIQUID
{% assign timer_mins = 10 %} <div id="urgency-timer" data-mins="{{ timer_mins }}"></div> <script> const key = 'cart_timer_end'; const mins = {{ timer_mins }}; if (!sessionStorage.getItem(key)) { sessionStorage.setItem(key, Date.now() + mins * 60000); } function tick() { const diff = sessionStorage.getItem(key) - Date.now(); if (diff <= 0) { document.getElementById('urgency-timer').textContent = 'Offer expired'; return; } const m = Math.floor(diff/60000), s = Math.floor((diff%60000)/1000); document.getElementById('urgency-timer').textContent = `Offer expires in ${m}:${String(s).padStart(2,'0')}`; setTimeout(tick, 1000); } tick(); </script>

avg. cart completion lift

SNIPPET 02 / 05
Real-Time Stock Counter
Pulls live inventory_quantity, shows scarcity badge only when stock is critically low (< 5 units). Zero fake numbers.
LIQUID
{% for item in cart.items %} {% assign qty = item.variant.inventory_quantity %} {% if qty > 0 and qty < 5 %} <p class="stock-warn"> ⚠️ Only {{ qty }} left — {{ item.title }} </p> {% endif %} {% endfor %}
+11%
add-to-cart rate on low-stock

SNIPPET 03 / 05
Free Shipping Progress Bar
Calculates gap to free shipping threshold and shows a live fill bar. One of the highest-ROI cart tweaks you can ship in a day.
LIQUID
{% assign threshold = 5000 %} {%- comment -%}in cents{%- endcomment -%} {% assign total = cart.total_price %} {% assign pct = total | times: 100 | divided_by: threshold %} {% if pct > 100 %}{% assign pct = 100 %}{% endif %} {% assign remaining = threshold | minus: total | money %} {% if total < threshold %} <p>Add {{ remaining }} more for free shipping</p> {% else %} <p>🎉 You've unlocked free shipping!</p> {% endif %} <div style="background:#eee;height:6px;border-radius:3px;"> <div style="width:{{ pct }}%;background:#FF9500;height:6px;border-radius:3px;"></div> </div>
+17%
AOV lift when bar is visible

SNIPPET 04 / 05
Exit-Intent Discount Reveal
Listens for mouse leaving viewport, then unhides a discount code block. Catches abandoners at the last second without a popup wall.
LIQUID
<div id="exit-offer" style="display:none; padding:16px;background:#fff3cd; border-radius:8px;"> Use code <strong>STAYWITHUS</strong> for 10% off — just for you. </div> <script> let shown = false; document.addEventListener( 'mouseleave', function(e) { if (e.clientY < 10 && !shown) { shown = true; document.getElementById('exit-offer') .style.display = 'block'; } }); </script>
+9%
recovery rate on abandoning

SNIPPET 05 / 05
Cross-Sell Block in Cart
Uses Shopify Product Recommendations API to surface one complementary product dynamically. Increases units per transaction without cluttering the cart.
LIQUID
{% if cart.item_count > 0 %} {% assign seed = cart.items.first.product_id %} <div id="cart-recs" data-product="{{ seed }}"></div> <script> fetch(`/recommendations/products.json ?product_id={{ seed }}&limit=1`) .then(r => r.json()) .then(data => { if (!data.products.length) return; const p = data.products[0]; document.getElementById('cart-recs') .innerHTML = `<p>You might also like: <a href="${p.url}">${p.title}</a></p>`; }); </script> {% endif %}
+8%
avg. units per transaction
