## What the post claims, and what it does not

Every number in the graphics and captions was read off the live myobvi.com homepage on
2026-08-02 at a 390×844 mobile viewport:

- $29.74 price and the "30% off" flag on Collagenic Fat Burner Capsules
- 1,489 review count on that product, 1,857 on Collagenic Burn Fast
- "OVER 800,000 HAPPY CUSTOMERS"
- GMP CERTIFIED / THIRD-PARTY TESTED / NON GMO
- H1 at 30px, hero paragraph at 13px (measured in-page, not estimated)
- SHOP NOW 150×44 at (26, 364), TAKE THE QUIZ 172×47 at (186, 364)

There is **no conversion-lift percentage, no A/B result, and no star rating** anywhere.
The live page shows five filled stars but no numeric average, so none was invented. Do not
add one when posting.

Obvi sells supplements. The FDA disclaimer stays on any caption that repeats a health
benefit.

## Before posting, worth a human look

1. The rebuild is a **concept**, not client work. Obvi did not commission this. The static
   ad set from 2026-07-11 carried an explicit "unofficial concept" line; these CRO Fix
   captions frame it as a teardown instead, matching how the V1CE and Material Kitchen
   posts were framed. If you want the stronger disclaimer here too, add it before posting.
2. Finding 3 (the accessibility widget overlapping SHOP NOW) is the sharpest hook in the
   post and it is a third-party widget's placement, not something Obvi's team hand-coded.
   The caption says so implicitly by calling it "the accessibility widget," but it is worth
   knowing if anyone replies.
